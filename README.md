<h3 align="left">Proyecto</h3>

📌 **Nombre**: Aplicación Mobile con API Rest  
🔗 **Repositorio**: https://gitlab.com/grup1_projecte3/projecte3  

Aplicación móvil que consume una API REST para la gestión y visualización de datos. La aplicación está desarrollada en Android utilizando Kotlin y Jetpack Compose para la interfaz de usuario, mientras que el backend está construido con Spring Boot siguiendo una arquitectura basada en servicios REST.

###

<h3 align="left">Funcionalidades</h3>

- Consumo de API REST desde la aplicación móvil
- Visualización dinámica de datos obtenidos del backend
- Navegación entre pantallas con arquitectura moderna de Android
- Interfaz moderna desarrollada con Jetpack Compose
- Comunicación entre cliente móvil y servidor mediante HTTP

<h3 align="left">Ejecución del proyecto</h3>

1. Clonar el repositorio  
2. Ejecutar el backend desarrollado con Spring Boot  
3. Abrir el proyecto móvil en Android Studio  
4. Configurar la URL de la API si es necesario  
5. Ejecutar la aplicación en un emulador o dispositivo Android
